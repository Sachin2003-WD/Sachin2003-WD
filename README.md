## 🚀 Signature Engineering Projects

### 📱 Attendrix

> **Smart QR-Based Attendance Management System**

Attendrix is a **Java Full Stack Smart Attendance System** designed to simplify batch-wise attendance management through secure QR-based attendance and role-based dashboards.

#### 🔹 Key Features

- 🔐 **Authentication & Authorization**
  - JWT-based authentication
  - Secure login and registration
  - Role-based access control
  - Protected application routes

- 👨‍🎓 **Student Management**
  - Student registration
  - Student profiles
  - Batch assignment
  - Attendance history
  - Attendance percentage

- 👨‍💼 **Admin Management**
  - Admin dashboard
  - Student management
  - Batch management
  - Attendance monitoring
  - Reports and analytics

- 📱 **Smart QR Attendance**
  - Daily QR code generation
  - QR-based attendance scanning
  - Batch-wise attendance validation
  - Duplicate attendance prevention
  - Attendance session validation

- 📊 **Attendance Tracking**
  - Daily attendance records
  - Batch-wise attendance
  - Present/Absent tracking
  - Attendance percentage
  - Attendance history
  - Search and filtering

- 📈 **Reports & Analytics**
  - Attendance summaries
  - Student attendance reports
  - Batch-wise reports
  - Attendance statistics

- 📱 **Responsive UI**
  - Mobile-friendly dashboards
  - Tablet support
  - Laptop support
  - Desktop support
  - Responsive tables and forms
  - Modern dashboard UI
